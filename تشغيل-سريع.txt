  طمأنينة v1.7.0 — دليل التشغيل السريع (Windows / Linux / Mac)
═══════════════════════════════════════════════════

✨ جديد v1.7.0:
  · بطاقة المحادثات (قبل الجلسة) بلا معاينة آخر رسالة نهائياً — الاسم والوقت فقط والضغط يفتح الدردشة كاملة (لا تشوّه هاتفياً مع الصوتية)
  · تبويب «مستحقات المختصين» بحساب الأدمين: لكل مختص جلساته المكتملة وأسعارها بعملتها وعمولة المنصة 15% ومستحق هذا الشهر + تفاصيل آخر الجلسات — نسخة إدارية من «إحصائياتي»

المتطلبات:
  1) Node.js 20 أو أحدث  → https://nodejs.org
  2) MongoDB (محلي على 127.0.0.1:27017 أو رابط Atlas)

خطوات التشغيل:
  1) افتح موجه الأوامر داخل مجلد المشروع
  2) npm install
  3) npm run build      ← مطلوب مرة واحدة قبل npm start
     (ملاحظة: هذه الحزمة تتضمن بناء إنتاجياً جاهزاً داخل .next —
      يمكنك تجربة npm start مباشرة، وإن لم يعمل نفّذ الخطوة 3 أولاً)
  4) npm start          ← http://localhost:3020

إعداد قاعدة البيانات (اختياري — .env):
  MONGODB_URI=mongodb://127.0.0.1:27017/tumaanina
  ADMIN_PASSCODE=كلمة-مرور-قوية-خاصة-بك
  (بدون .env تعمل المنصة محلياً بالقيم الافتراضية إن كان MongoDB محلياً)

⚠️ مهم — تثبيت التطبيق (PWA):
  المنفذ الافتراضي الآن 3020 وليس 3000.
  إن كان لديك تطبيق منصة أخرى مثبّتاً من localhost:3000 في نفس المتصفح
  فسيظهر باسمه القديم — احذفه من قائمة التطبيقات المثبتة أولاً،
  ثم ثبّت طمأنينة من http://localhost:3020 وسيظهر باسم «طمأنينة»
  وأيقونة اللوتس البنفسجية.

👥 فريق الإدارة (v1.4.0):
  - دخول المالك برمز ADMIN_PASSCODE (من .env) — وحده يرى تبويب «فريق الإدارة»
  - أنشئ حسابات «مدير منصة» أو «مسير» بالبريد وكلمة مرور من ذلك التبويب
  - المسير: قراءة اللوحات والمحتوى والإشعارات فقط — كل الصلاحيات محمية تحققاً خادمياً

✨ جديد v1.5.0 (الجولة الشاملة):
  - السعر بصيغة «2 500 دج» (الرقم ثم الرمز) في كل مواضع المنصة + زر واتساب مباشر
    في بطاقة الأخصائي.
  - نافذة طلب الحجز تظهر للأخصائي أينما كان (لا في لوحته فقط) — والنقر على أي إشعار
    يفتح صفحته المرتبطة مباشرة، وإشعارات الهاتف باتجاه اللغة (RTL/LTR).
  - الدردشة: تعديل وحذف رسائلك + رسائل صوتية بالمايك + كسر أسطر مضمون لأطول النصوص.
  - الجدولة التالية تعرض مواعيد الأخصائي المتاحة فقط (ناقص المحجوز)، ونافذة
    «الجلسة التالية + المزاج» تصل للعميل فور الجدولة.
  - شارة «العميل في الغرفة الآن» + البدء المبكر يُحتسب التزاماً في تحدّي العملاء
    + أشرطة تقييم بنسب واقعية + توثيق الإدارة مضمون في كل مرة.

💡 نموذج العمل (v1.3.0):
  - ثلاث عملات مستقلة: الأخصائي يحدد سعر جلسته لكل عملة (دج/يورو/دولار) من إعداداته
    وبلا أي تحويل — والعميل يرى سعر العملة التي يختارها فقط.
  - الرابط العام للمختص يعرض السعر بكل العملات المتوفرة.
  - لا توجد محفظة ولا دفع إلكتروني: السعر يظهر للعميل بوضوح في
    بطاقة الأخصائي وفي نافذة الحجز، ويُدفع مباشرة وفق اتفاق الطرفين.

أول خطوة بعد التشغيل:
  1) افتح http://localhost:3020
  2) سجّل أخصائياً من «انخراط كأخصائي» (ارفع صورة الشهادة)
  3) ادخل لوحة الإدارة من الفوتر → «إدارة المنصة» ووثّق الأخصائي
  4) سجّل عميلاً واحجز أول جلسة — سترى السعر بالدينار في كل خطوة الحجز
